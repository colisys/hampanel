# 端口穿透（管理端）

端口穿透完全运行在 **管理端（Flutter 客户端）**，不写入远端配置文件，也不向 daemon
注册 systemd 服务。远端只承担 SSH 服务端角色。

## 模式

| 模式 | SSH 参数 | 监听位置 | 说明 |
| --- | --- | --- | --- |
| 本地转发 | `-L 127.0.0.1:<本地端口>:<目标主机>:<目标端口>` | 管理端回环 | 通过 SSH 访问远端网络中的服务 |
| 反向转发 | `-R 127.0.0.1:<远端端口>:<目标主机>:<目标端口>` | 远端回环 | 把管理端本地服务暴露到远端回环 |
| SOCKS | `-D 127.0.0.1:<本地端口>` | 管理端回环 | 经远端出网的 SOCKS5 代理 |
| socat | `TCP-LISTEN:<本地端口>,fork,reuseaddr` → `TCP:<目标主机>:<目标端口>` | 管理端回环 | 本机中继，需要安装 socat |

- 所有监听都只绑定 `127.0.0.1`，不会意外暴露到公网或局域网。
- `-R` 的远端监听同样固定为远端回环地址。
- SOCKS 仅在 **管理端 Linux + 远端 Linux** 时可用；远端平台从 `/api/v1/system` 读取，
  管理端平台由 `Platform.isLinux` 判断。
- socat 模式检测本机 `socat -V`；未安装时选项禁用。

## 跳板机 `-J`

- 支持一层跳板机，填写 `[user@]host[:port]`，例如 `ops@bastion.example.com:2222`。
- 不接受逗号分隔的多级跳板、空格或 shell 分隔符。
- 跳板机与目标主机暂不支持 IPv6 字面量。
- SSH 私钥路径可留空使用 agent/默认密钥；路径支持 `~/` 展开。

## 安全策略

- 仅使用固定参数调用 `ssh`：
  `BatchMode=yes`、`ExitOnForwardFailure=yes`、`StrictHostKeyChecking=accept-new`、
  `PasswordAuthentication=no`，不读取任意 SSH 配置或 `ProxyCommand`。
- 仅支持密钥/agent 认证，不保存密码；配置保存在管理端 `tunnels.json`（无密钥内容）。
- 跳板机、主机、用户、端口都经过严格校验，参数通过 argv 传递，不经过 shell。
- 隧道进程由管理端启动和停止；应用退出或重新登录时请确认已停止隧道进程。

## 使用建议

- 需要访问远端数据库/管理端口：使用 `-L`。
- 需要把本地开发服务暴露给远端：使用 `-R`。
- 需要浏览器或工具经远端出网：使用 `-D`。
- socat 是纯本机中继；若目标在远端，请使用 `-L`（socat 不参与 SSH）。
