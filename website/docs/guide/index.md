# 产品概述

Hampanel 是一个开源服务器运维面板。它由两部分组成，缺一不可：

| 组件 | 技术 | 运行位置 | 作用 |
| --- | --- | --- | --- |
| **客户端** | Flutter | 你的电脑或手机 | 操作界面，保存主机凭据 |
| **受控端** | Zig（`hampaneld`） | 被管理的服务器 | 执行实际操作，签发与校验证书 |

客户端与服务端之间是**双向 TLS** 连接，不是浏览器打开的网页后台。所有功能通过受控端 API 执行，不经过 Shell 拼接。

## 和网页面板的区别

- **界面跑在本地。** 桌面与移动端原生客户端，不受浏览器标签页限制，凭据保存在你的设备上。
- **服务端只暴露 API。** 没有对外提供的管理页面，减少一层被扫描和爆破的入口。
- **证书即身份。** 没有项目 CA 签发的客户端证书，TLS 握手直接失败，不存在密码登录表单。

## 适合的场景

- 管理一到多台 Linux 或 Windows 服务器，想用一个客户端集中切换。
- 需要文件、终端、服务、容器、站点、防火墙这类日常操作在同一处完成。
- 希望通过 Compose 快速部署常见服务，而不是每次手写编排。
- 对远程管理通道的安全性有要求，倾向证书认证而非口令。

## 不适合的场景

- **多用户、分角色授权的团队协作。** 面板是单管理员模型，没有账号体系与 RBAC。
- **只想要网页面板。** 客户端必须安装，服务器上不提供 Web 管理界面。
- **管理 macOS 本机。** macOS 与移动端只运行客户端，不作为受控端。
