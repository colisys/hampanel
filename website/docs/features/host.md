# 概览与主机运维

## 概览

连接主机后进入 **概览**，查看主机信息、负载、CPU、内存、磁盘与网络趋势。网络图可在右上角切换网卡，刷新间隔在同一位置调整。概览同时显示当前连接的心跳状态，心跳中断说明客户端到受控端的连接已经断开。

多台主机可在侧栏切换当前会话，查看各自主机的指标。

## 任务

面板的长操作都走任务队列：商店部署、运行环境构建、软件安装、服务动作、受控端更新。

1. 打开 **任务**，按状态筛选（排队、运行、成功、失败、已取消）。
2. 打开某条任务查看增量输出；卡住或选错参数时可直接取消。
3. 结束的任务可以删除记录，记录删除只影响列表，不回滚已经执行的操作。

任务持久化在 SQLite 中。重启后排队任务继续执行；已经运行中的任务不保证断点续跑，需要重新发起。部分 Docker 专用操作走独立的 `/docker/jobs` 通道，与任务中心分开。

## 进程

- 按 PID、名称、命令搜索。
- 查看详情，发送 TERM 或 KILL。先发 TERM，进程无响应时再用 KILL，后者不给进程收尾机会。
- Linux 详情包含 exe、cwd、线程数、打开文件与监听端口。

Windows 的终端走 `cmd.exe` 管道，不是 ConPTY，全屏终端程序的表现与 Linux 不同；进程详情字段也比 Linux 少。

## 终端

基于 PTY 的 WebSocket 交互终端，适合跑常规命令与交互程序。

- **多会话**：侧栏列出所有会话（移动端用底部选择器），可同时开多个 shell，各自独立；会话标题跟随 shell 更新。需要并行排查时先新建会话，避免在同一个 shell 里互相干扰。
- **复制与粘贴**：工具栏提供入口；快捷键为 `Ctrl+Shift+C` / `Cmd+C` 复制、`Ctrl+V` / `Ctrl+Shift+V` / `Cmd+V` 粘贴。有选区时只复制选区，否则复制整屏输出。
- **外观可调**：字号、行高、光标形状与配色。这些设置只保存在管理端本地，不随受控端同步。

修改网络、SSH 或防火墙配置前，建议先在终端另开一个会话并保持登录，配置出错时可以用它恢复。

## 服务

1. 打开 **服务**，按名称或状态搜索 systemd 单元。
2. 在单元菜单执行启动、停止、重启、重载，以及开机自启的启用与禁用。
3. 打开日志面板搜索关键字，长日志按行数截断。
4. Linux 可查看和编辑服务配置；修改前记录原值，保存后检查服务状态与日志。

## 日志

统一日志页把各类日志收在一处：

- **面板审计**：记录经过面板的请求。
- **系统日志**与各类服务日志：可搜索，按级别与时间筛选。

排障时先确定时间点，再用时间范围收窄，最后用关键字定位。日志页读取的是受控端指定的日志来源，不提供任意路径的文件读取。

## 计划任务

1. 打开 **计划任务**，选择添加用户任务，填写执行周期与命令。
2. 列表按用途分成面板自身的更新 / 检查任务，与操作者添加的用户任务。
3. 修改后检查任务列表；不再需要时从列表中删除。

面板管理其托管的 crontab 区块。Windows 的任务映射到任务计划程序，只支持常见表达式，复杂表达式返回 501。

## 主机设置

Linux 下可管理：

- Swap：交换文件或已有交换设备。
- NTP 时间同步。
- GRUB2 启动项。
- `/etc/hosts`。

修改 `/etc/hosts` 或 GRUB 默认启动项前记录原值，改动会在下次启动或立即生效，影响范围是整个主机。这些是 Linux 专有能力，Windows 没有对应界面。
