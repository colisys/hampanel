# 概览与主机运维

## 概览

显示主机信息、负载、CPU、内存、磁盘与网络趋势。网卡可切换，刷新间隔可调。多台主机时在侧栏切换会话，概览会显示当前连接的心跳状态。

## 任务

面板的长操作都走任务队列：商店部署、运行环境构建、软件安装、服务动作、受控端更新。

- 状态：排队、运行、成功、失败、已取消。
- 查看增量输出，随时取消，删除已结束的记录。
- 任务持久化在 SQLite 中。重启后排队任务继续执行；已经运行中的任务不保证断点续跑。

部分 Docker 专用操作走独立的 `/docker/jobs` 通道，与任务中心分开。

## 进程

- 按 PID、名称、命令搜索。
- 查看详情，发送 TERM 或 KILL。
- Linux 详情包含 exe、cwd、线程数、打开文件与监听端口。

Windows 的终端走 `cmd.exe` 管道，不是 ConPTY，全屏终端程序的表现与 Linux 不同；进程详情字段也比 Linux 少。

## 终端

基于 PTY 的 WebSocket 交互终端，适合跑常规命令与交互程序。

- **多会话**：侧栏列出所有会话（移动端用底部选择器），可同时开多个 shell，各自独立；会话标题跟随 shell 更新。
- **复制与粘贴**：工具栏提供入口；快捷键为 `Ctrl+Shift+C` / `Cmd+C` 复制、`Ctrl+V` / `Ctrl+Shift+V` / `Cmd+V` 粘贴。有选区时只复制选区，否则复制整屏输出。
- **外观可调**：字号、行高、光标形状与配色。这些设置只保存在管理端本地，不随受控端同步。

## 服务

- 列出 systemd 单元，执行启停、重启、重载、开机自启的启用与禁用。
- 查看并搜索服务日志，按行数截断。
- Linux 可查看和编辑服务配置。

## 日志

统一日志页把各类日志收在一处：

- **面板审计**：记录经过面板的请求。
- **系统日志**与各类服务日志：可搜索，按级别与时间筛选。

日志页读取的是受控端指定的日志来源，不是任意路径文件读取器。

## 计划任务

管理面板托管的 crontab 条目，并按用途分成两类：面板自身的更新 / 检查任务，与操作者添加的用户任务。两者分开呈现，避免和面板内部排程混在一起。

只管理面板托管的区块，不接管整张 crontab。

Windows 映射到任务计划程序，只支持可映射的常见表达式，复杂表达式会返回 501。

## 主机设置

Linux 下可管理：

- Swap：交换文件或已有交换设备。
- NTP 时间同步。
- GRUB2 启动项。
- `/etc/hosts`。

这些是 Linux 专有能力，Windows 没有对应界面。
