# 数据库与 GraphQL

「数据库」操作已登记的服务器实例；「GraphQL」向任意 HTTP(S) 端点发送请求。两者都在一级导航中。

## 登记数据库实例

1. 确认目标数据库已经运行，受控端可以访问它；若是容器，请先在[容器页](/features/containers)确认引擎与容器状态。
2. 进入 **数据库 → 登记实例**，选择 MySQL、MariaDB、PostgreSQL、MongoDB 或 Redis，并选择 **主机** 或 **Docker / Podman 容器**连接方式。
3. 填写名称、主机地址、端口、管理账号、密码；容器模式还需填写容器名称或 ID。Socket 路径可选，取值来自**受控端**文件系统。
4. 保存后按引擎分类找到实例并打开。若读取失败，检查服务状态、网络可达性和账号权限。编辑实例时密码留空表示保留原密码。

移除登记只删除连接信息，数据库本身保持不变。数据库服务的安装可以用[应用商店](/store/)。

## 管理库与备份

打开非 Redis 实例后，可以查看数据库与实例账号，并使用 **创建数据库**、**创建账号** 或 **重置管理账号密码**。打开某个数据库后，可查看表（MongoDB 为集合）并点击 **创建备份**；备份列表的菜单提供下载与恢复。

恢复会**覆盖该数据库当前内容**，删除数据库是永久操作；两者都要求输入数据库名称确认。恢复前先下载当前备份，并在非生产环境验证备份可用性。备份文件生成在受控端，下载后保存到客户端设备。Redis 实例打开后进入专用命令行。

## GraphQL 请求台

1. 打开 **GraphQL**，填写目标服务的 HTTP(S) 端点（例如 `https://example.com/graphql`）。
2. 填写 GraphQL 查询；如有变量或自定义请求头，分别填写 **JSON 对象**，例如 `{"id":"123"}` 和 `{"Authorization":"Bearer …"}`。
3. 点击 **执行查询**，在下方查看 HTTP 状态与格式化后的 JSON 响应；非 JSON 响应会原样展示。

请求由当前客户端所在网络直接发出，因此端点必须对该网络可达。不要把生产密钥粘贴到截图或工单中。
