# AI 助手与通知

## AI 助手

AI 助手运行在**管理端**，不部署在服务器上。

### 模型接入

支持 OpenAI 兼容的两类接口：

- Chat Completions（流式）
- Responses

### 会话

本地保存多个会话，可新建、切换、删除。回复支持 Markdown、代码块与表格渲染。

### 工具权限

在系统设置中勾选允许的工具，并指定敏感文件路径。

| 工具类别 | 默认行为 |
| --- | --- |
| 普通只读工具 | 满足条件时自动执行 |
| 敏感文件读取 | 需人工批准 |
| 修改类操作 | 逐次展示参数，确认后执行 |
| 日志读取 | 默认关闭；开启后先让你审阅、删改拟发送的日志 |
| 创建计划任务 | 默认关闭 |

AI **没有通用 shell 工具**。删除文件只能走回收站。

### 密钥保存

- 桌面端：系统钥匙串。
- 移动端：应用私有文件。

## 通知

支持 Bark 与 ntfy 推送，可在面板内配置并发送测试消息。

触发通知的事件包括登录、AI 执行操作等。通知之外，另有审计日志记录面板请求，两者用途不同。

## 审计

审计日志记录经过面板的请求，用于回溯谁在什么时候做了什么。查看入口在「日志」页。
