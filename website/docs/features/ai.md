# AI 助手与通知

## AI 助手

AI 助手在**管理端**运行，通过受控端 API 读取信息并执行被允许的操作。

### 配置

打开 **AI 助手 → 配置**，选择协议，填写 Base URL、模型和 API Key，保存后发送一条测试消息。支持 OpenAI 兼容的 Chat Completions（流式）与 Responses。工具权限在 **设置 → AI** 单独配置。

密钥在桌面端保存到系统钥匙串，移动端保存到应用私有文件。切换主机不影响 AI 配置。

### 会话

本地保存多个会话，可新建、切换、删除。回复支持 Markdown、代码块与表格渲染。会话记录随会话保存在本地，删除后不可恢复。

### 工具权限

在 **设置 → AI** 中勾选允许的工具，并指定敏感文件路径。

| 工具类别 | 默认行为 |
| --- | --- |
| 普通只读工具 | 满足条件时自动执行 |
| 敏感文件读取 | 需人工批准 |
| 修改类操作 | 逐次展示参数，确认后执行 |
| 日志读取 | 默认关闭；开启后先让你审阅、删改拟发送的日志 |
| 长操作（提交任务） | 默认关闭；提交后可用另外两个工具查看状态与取消 |
| 创建计划任务 | 默认关闭 |

AI 可以提交长操作任务、查询任务状态与取消任务，耗时操作不会阻塞对话。审批时逐项核对目标主机、路径与参数，再决定是否执行。

### 能力边界

AI 只使用上面启用的工具，没有通用 shell。删除文件走回收站，可从回收站恢复。

## 通知

1. 在 **设置 → 通知** 选择 Bark 或 ntfy，填写服务器地址、设备密钥或主题，并勾选启用。
2. 先保存，再用卡片上的测试按钮发送测试消息，确认能收到推送。
3. 按需调整提示音、优先级或分组；修改后重新保存。

通知由受控端按已保存的 Bark / ntfy 配置发送；查看请求记录可打开审计日志。

## 审计

审计日志记录经过面板的请求，查看入口在 **日志 → 面板审计**。排查异常操作时，按时间、路径和响应状态筛选。
