# 功能总览

客户端一级导航的顺序：**概览、任务、AI 助手、进程、文件、终端、端口穿透、服务、数据库、GraphQL、网站、容器、应用商店、运行环境、软件、安全中心、计划任务、日志、设置**。端口穿透在移动端隐藏，回收站不是一级导航，位于文件管理内。SSH、WAF、防火墙与 Fail2ban 收在安全中心，不再是一级导航。

下面按功能页面归类说明。

数据库与 GraphQL 各有一个一级导航页：

- **数据库**：登记 MySQL / PostgreSQL / MongoDB / Redis 实例（宿主机或容器），查看库、账号与表，执行查询，备份 / 下载 / 恢复；Redis 使用专用控制台。
- **GraphQL**：本地请求台，填写端点、查询、变量与请求头，格式化响应，便于调试自建服务。

## 三组容易混淆的概念

初用时最常搞混的地方：

### 管理端与受控端

界面上的所有操作都在**受控端**执行。客户端本身不接触服务器文件系统，只是发起 mTLS 请求。所以「在哪台机器上操作」比「在哪个平台打开客户端」更重要。

### 任务与计划任务

- **任务**（导航里有单独页面）是一次性的长操作队列：软件安装、运行环境构建、商店部署、服务动作。可以看进度、取消、删记录。
- **计划任务**是定时执行，管理面板托管的 root crontab 条目。

两者完全无关，只是名字接近。

### 网站证书与 WAF 的 TLS

- **网站证书**在站点详情页上传，作用于该站点的 HTTPS 监听。
- **WAF 的 TLS** 是边缘代理自己的证书，在 WAF 页面配置。

两者作用于不同层，不要互相替代。
