# 功能总览

## 概念对照

### 管理端与受控端

操作都在**受控端**执行，客户端只负责界面与发起 mTLS 请求。同一条操作，走哪个客户端平台都一样，结果取决于连接的是哪台服务器。

### 任务与计划任务

- **任务**：一次性长操作队列，包含软件安装、运行环境构建、商店部署、服务动作、受控端更新。可查看进度、取消、删除记录。重启后排队的任务继续执行。
- **计划任务**：定时执行的 crontab 条目，由面板托管。

### 网站证书与 WAF 的 TLS

- **网站证书**：在站点详情页上传，作用于该站点的 HTTPS 监听。
- **WAF 的 TLS**：边缘代理自身的证书，在 WAF 页面配置。

两层分别配置：站点证书不随 WAF 生效，WAF 证书也不改变源站的证书。
