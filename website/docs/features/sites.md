# 网站与证书

## 站点类型

先在服务器上准备站点文件或可访问的上游服务，并确认 80 / 443 或自定义监听端口没有与其他服务冲突。打开 **网站 → 新建站点**，选择 Web 服务器后再选择类型、域名及监听配置；Windows 受控端不提供网站管理。站点支持的类型包括：

| 类型 | 用途 |
| --- | --- |
| 静态网站 | 直接提供目录下的静态文件 |
| 反向代理 | 转发到本机或远端的上游服务 |
| 运行环境 | 绑定一个运行环境容器 |
| 子网站 | 依附于父站点的子路径 |
| TCP 代理 | 四层转发 |
| UDP 代理 | 四层转发 |

## 配置项

创建后打开站点详情，按需要配置证书、认证、重定向或代理等选项。涉及上游的站点需确认受控端能连接上游；子网站需先有父站点。

站点详情页提供：

- 证书上传
- Basic Auth
- 重定向
- 伪静态规则
- 自定义日志路径

保存站点配置时，受控端会校验 Web 服务器配置并重载；保存后从客户端访问域名验证响应。启用公网访问还需检查域名解析、宿主防火墙和云安全组。

## Web 服务器

站点可运行在三种后端上：

1. **宿主 Nginx**：直接使用系统安装的 Nginx。
2. **受管 Nginx 容器**：应用商店部署的 Nginx，由面板管理配置与挂载。
3. **Caddy**：Caddy 模式明确不支持限流、防盗链、真实 IP 与独立错误日志。

受管容器的配置与数据通过宿主机目录挂载，容器内使用相同的绝对路径。因此宿主上能用的证书路径、认证文件、日志目录在容器里同样有效。

## 证书

在站点详情页上传证书与私钥，再为站点启用 HTTPS。证书需覆盖站点域名。启用后用浏览器检查证书链和到期时间。

需要自动签发与续期时，使用应用商店的 Certbot（standalone 模式）：先停占用 80 端口的服务，签发完成后在站点中引用生成的证书文件。

公众可达域名也可以交给 [WAF](/features/network#waf) 的边缘代理自动签发，两层配置分别生效。

## 日志

站点日志按站点查看。自定义日志路径写在站点配置中，宿主与容器模式都按该路径写入。

## 启停与删除

站点可以单独启停。删除时确认后移除面板托管的站点配置并重载 Web 服务器；网站目录内容保持不变。
