# 文件与恢复

## 文件管理

- 浏览目录，查看类型、权限、属主等元数据。
- 读取与在线编辑文本文件。
- 新建、重命名、上传、下载。
- 删除的条目进入回收站，不直接从磁盘移除。

后端另有账户列表和权限/属主修改接口。它服务于文件操作，不等于完整的系统用户管理器。

## 回收站

通过面板删除的文件或目录可以从回收站恢复到原路径。原位置已有同名内容时不会直接覆盖，需先处理冲突。

永久删除与清空回收站是独立操作，需要确认。

回收站只覆盖面板发起的删除。终端里执行的 `rm`、容器内的删除、删除数据卷都不进入回收站。

## 历史版本

在线编辑、上传覆盖、AI 写文件之前，会先保存旧内容：

- 每个文件最多保留最近 20 个版本。
- 恢复某个版本时，当前内容也会先存为一个新版本。

历史版本是按文件的内容快照，不是整机备份，也不包含权限、属主之外的系统状态。

## 软件托管

软件页显示宿主软件的安装与托管状态，区分「已安装」与「待初始化」。

**初始化**是接管配置的动作：停止服务、写入面板管理的配置、再启动。可能短暂停服，需要显式确认。

### Fail2ban

卡片内可直接管理：

- 查看 jail、失败次数与封禁统计。
- 手动封禁或解封 IPv4 / IPv6 地址。
- 调整 `maxretry`、`bantime`、`findtime`，校验后重载。

### SSH

SSH 有独立页面，见[网络接入与防护](/features/network#ssh)。

::: tip 托管的范围
商店能安装某个软件，不代表面板接管它的全部配置。哪些配置可在面板内修改，以对应页面为准。
:::
