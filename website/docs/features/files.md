# 文件与恢复

## 文件管理

连接服务器后打开 **文件**，在路径栏定位受控端的目录；列表中展示的是服务器文件。选择文件可读取或编辑文本，文件菜单提供 **历史版本**、**权限**、**重命名**、**下载** 和 **删除**，目录也可重命名或删除。上传时选择客户端本地文件，目标目录已有同名文件时请先确认覆盖影响。

- 浏览目录，查看类型、权限、属主等元数据。
- 读取与在线编辑文本文件。
- 新建、重命名、上传、下载。
- 删除的条目进入回收站。

权限与属主修改接口服务于文件操作，系统用户管理不在本页。

## 回收站

在 **文件 → 回收站** 查看已删除条目，选择目标后恢复或永久删除；清理全部条目时使用清空操作。恢复前确认原路径可写。

通过面板删除的文件或目录可以从回收站恢复到原路径。原位置已有同名内容时需要先处理冲突。

永久删除与清空回收站是独立操作，需要确认。

回收站覆盖面板发起的删除。终端中的 `rm`、容器内的删除与删除数据卷不进入回收站。

## 历史版本

在文件列表中打开目标文件的菜单，选择 **历史版本**，核对时间和内容后再恢复。在线编辑、上传覆盖、AI 写文件之前，会先保存旧内容：

- 每个文件最多保留最近 20 个版本。
- 恢复某个版本时，当前内容也会先存为一个新版本。

历史版本按文件保存内容快照，权限与属主等系统状态不在其中。整机备份请使用[数据与目录](/reference/data#备份)列出的范围。

## 软件托管

软件页显示宿主软件的安装与托管状态，区分「已安装」与「待初始化」。

需要接管已安装软件时，在 **软件** 页检查卡片的托管状态，再选择 **初始化** 并确认影响。**初始化**会停止服务、写入面板管理的配置、再启动，过程可能短暂停服；先备份原配置并安排维护窗口。

### Fail2ban

卡片内可直接管理：

- 查看 jail、失败次数与封禁统计。
- 手动封禁或解封 IPv4 / IPv6 地址。
- 调整 `maxretry`、`bantime`、`findtime`，校验后重载。

### SSH

SSH 有独立页面，见[网络接入与防护](/features/network#ssh)。

::: tip 托管的范围
商店负责安装，面板对配置文件的管理范围以各功能页提供的选项为准。
