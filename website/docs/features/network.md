# 网络接入与防护

SSH、WAF 与防火墙的入口现在都收在[安全中心](/features/security)的卡片里，本章讲的是它们各自的具体操作。端口穿透仍在导航中。

## SSH

管理**目标机**的 sshd，分三个标签页：

- **概览**：sshd 状态与生效配置；修改端口、root 登录、密码登录、公钥登录策略。
- **密钥**：按用户管理 `authorized_keys`。
- **日志**：查看 journal、auth 与文件日志，可选择写入 rsyslog 文件。

配置修改先校验，失败会回滚。**改端口不会自动开放防火墙或云安全组**，请在保留现有会话的情况下操作，并同步调整放行规则。

这是管理服务器的 SSH 服务，不是登录面板用的连接方式。

## 防火墙

查看现有规则，新增放行或拒绝规则，删除规则。

- Linux 对应 UFW。
- Windows 对应系统防火墙。

这里管理的是宿主防火墙，与云厂商的安全组、与下面的 WAF 都是不同的层。

## WAF

在 Linux 上构建 Caddy + Coraza + 内嵌 OWASP CRS 的边缘代理：

- 配置监听地址与上游源站。
- 按 Host 或通配域名设置策略。
- 三种模式：关闭、检测（只记录）、阻断。切换阻断需要确认。
- 配置 TLS、GeoIP/GeoSite。
- 可选 TypeSafe 风险复检与风险日志。
- **暴力破解封禁**：对反复失败的登录请求按来源计数，超过阈值即临时封禁。
- **浏览器指纹**：为请求生成指纹，便于识别同一来源的自动化工具。

源站仍需你自行限制直连。面板不会自动把现有站点的公网监听迁移到 WAF 后面。

TypeSafe 是外部复检服务，启用后请求数据会发送到该服务。相关密钥通过 systemd-creds 管理。

## 端口穿透

在**桌面管理端**上发起隧道，不在服务器部署常驻服务：

| 类型 | 说明 |
| --- | --- |
| 本地 SSH 转发 | 把远端端口映射到本机 |
| 反向 SSH 转发 | 把本机端口暴露到远端 |
| 动态 SOCKS | 本机 SOCKS 代理，要求两端都是 Linux |
| socat 中继 | 本机端口转发，要求本机安装 socat |

- 监听地址限定回环。
- SSH 转发支持一层跳板，可使用私钥或 agent。
- 移动端不显示该功能。

这与应用商店里的 FRPS / frpc 是两套不同入口：前者是临时的本地隧道，后者是部署在服务器上的常驻服务。
