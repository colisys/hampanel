# 脚本与 Nix

## 系统工具

打开 **应用商店 → 系统工具**，先检查页面识别出的 Linux 包管理器，再选择工具并点击安装。安装后到 **任务** 页查看输出；找不到所需工具时填写自定义包名，必要时先刷新包索引。

支持的包管理器：apt、dnf、yum、zypper、pacman、apk。

- 内置精选工具可直接安装，例如 Git、htop、jq、ripgrep。
- 也可以输入自定义包名安装。
- 可以刷新包索引。

在 **软件** 页查看安装后的托管状态；需要让面板接管配置时，再按卡片提示初始化。

## Nix

服务器已安装 Nix 时，在 **应用商店 → Nix** 选择精选目标或填写允许的 nixpkgs 属性，选择 **构建** 或 **运行**，在 **任务** 页查看输出。首次进入时先检查 Nix 状态；缺失时按页面提示安装。

属性名使用受限格式。仓库自带 `flake.nix`，从仓库根目录也可以运行：

```bash
nix build .#default
nix run .#default -- version
nix develop
```

## 任务输出

商店操作在受控端执行。打开 **任务** 查看执行进度、输出和失败原因。
