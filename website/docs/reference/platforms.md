# 平台差异

## 受控端

| 平台 | 受控端 | 说明 |
| --- | --- | --- |
| Linux（glibc / musl） | ✅ | systemd、`/proc`、UFW、crontab、PTY，功能基线 |
| Windows 10/11、Server 2019+ | ✅ | 以 Windows 服务运行；防火墙、任务计划、进程、磁盘、网络走系统 API |
| macOS | — | 只运行客户端 |
| Android / iOS | — | 只运行客户端 |

Linux 上的能力是完整基线。Windows 的下述差异来自系统模型的差别，属于实现边界：

| 功能 | Windows 表现 |
| --- | --- |
| 网站管理 | 不提供 |
| WAF | 不提供 |
| 系统工具包安装 | 不提供 |
| 终端 | `cmd.exe` 管道，不是 ConPTY，全屏终端程序表现不同 |
| 进程详情 | 字段比 Linux 少 |
| 计划任务 | 映射到任务计划程序，只支持可映射的常见表达式，复杂表达式返回 501 |
| 主机设置 | Swap、NTP、GRUB2、`/etc/hosts` 不适用 |

Windows 另有可选的内核伴随驱动（`hampanel.sys`），通过控制设备暴露存活与版本信息。它不承担 HTTP/TLS，管理 API 全部留在用户态。

## 客户端

| 平台 | 版本要求 | 说明 |
| --- | --- | --- |
| Linux | 主流桌面发行版 | AppImage，依赖系统 GTK3 |
| Windows | 10/11、Server 2019+ | 单文件绿色版 |
| macOS | 13+ | 按 Metal 能力选 Impeller 或 Skia |
| Android | — | 抽屉式主菜单 |
| iOS | — | 未签名 IPA，需自行签名 |

### 移动端差异

移动端是管理端，保留日常操作，少了两项桌面能力：

- 没有端口穿透（本机隧道）。
- 没有打开配置目录的入口。

文件选择与保存走系统文件选择器，不同平台的交互名称不同。

## 功能与平台对照

| 能力 | Linux | Windows | macOS | 移动端 |
| --- | --- | --- | --- | --- |
| 服务器管理 | ✅ | ✅ | — | — |

| 应用商店 Docker 应用 | ✅ | ✅ | — | — |

| 端口穿透 | ✅ | ✅ | ✅ | — |
| AI 助手 | ✅ | ✅ | ✅ | ✅ |
