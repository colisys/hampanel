# 常见问题

## 客户端连不上服务器

按顺序排查：

1. `systemctl status hampanel`（Windows：`Get-Service hampanel`）确认服务在运行。
2. 防火墙或云安全组是否放行了受控端端口。
3. 凭据是否对应这台主机，endpoint 与端口是否正确。
4. 连接成功但接口 404，说明入口前缀没随凭据导入。

握手直接失败通常是证书问题；能连上但请求失败多数是前缀或权限问题。

## 安装后没有生成 enroll.json

安装器在生成 PKI 之后才输出凭据。检查安装日志末尾是否有错误，以及配置目录是否可写。源码模式与二进制模式都会生成该文件。

## 为什么没有 stable 版本

`stable` 对应正式 tag。仓库当前以 nightly 分支发布滚动预发布，所以安装时要用 `--channel nightly`。正式版发布后，`stable` 会自动指向它。

## 面板能管理 macOS 本机吗

不能。macOS 只运行客户端。受控端只支持 Linux 和 Windows。

## 容器和网站为什么有时对不上

站点可以使用宿主 Nginx、受管 Nginx 容器或 Caddy。不同后端的可配置项不同：Caddy 模式不支持限流、防盗链、真实 IP 与独立错误日志。先确认站点用的是哪个后端，再看对应配置项。

## 改 SSH 端口后连不上

改端口不会自动开放防火墙或云安全组。规则没同步时，现有会话之外的连接会立即中断。提前放行新端口，并保留一个已登录的会话。

## 卸载商店应用后数据还在

默认卸载保留命名卷。要删除数据需选择「卸载并删除数据」。删除后不进入回收站，也无法通过历史版本恢复。

## 任务重启后会继续吗

排队中的任务会继续。已经运行中的任务不保证断点续跑，需要重新发起。

## Docker 和 Podman 都需要吗

不需要。首次启动时探测到哪个就用哪个，并把结果写入配置。之后固定使用该值，不会每次请求重新选择。

## AI 助手能执行任意命令吗

不能。AI 没有通用 shell 工具，删除文件只能走回收站。修改类操作每次都要你确认参数；读取日志默认关闭，开启后也会先让你审阅内容。
